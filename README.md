# Sundance

An isometric, pixel-art spaghetti western in Godot 4, drawing on Leone, Corbucci and Sollima.
One stranger, the border town of San Miguel, ten bandits. See [DESIGN.md](DESIGN.md).

## Play

Open the folder in Godot 4.7 and press Play, or run:

```bash
godot --path .
```

WASD move · mouse aim · LMB fire · RMB fan the Colt / fire both barrels · C or Ctrl crouch ·
R reload (fire stops a partial reload) · 1/2/3 or wheel to switch guns · E knife (hold to drag
a body; at the gallows or the pole, hold to cut the man loose; by the machine gun, get on or off it; by the plunger, fire the mines; by the strongbox, take it up or set it down) · B bandage · G throw dynamite · F swap for the gun at your feet · Enter restart · Esc quit.

The window can be any size. A bigger one shows more of the town, up to about 640x360 world
pixels on a 16:9 screen (wider on a 21:9 one); past that the pixels only get bigger. A
1280x720 window shows what it always has.

On the loadout screen: 1/2/3 or a click go through a slot's guns (those you can afford), B and G
buy a bandage and a stick of dynamite, Enter rides in. Each gun and piece of kit costs points out
of the level's budget.

## Assets

Every sprite and sound is generated by `tools/gen_assets.py`: a small point-splat 3D renderer
draws the 8-direction characters, buildings and props in 2:1 isometric pixel art, and the
sounds are synthesised. Each map is laid out by its own script, `tools/make_town.py`
(San Miguel, `data/town.json`), `tools/make_cruz_verde.py` (`data/cruz_verde.json`) and
`tools/make_train.py` (Paso Esperanza, `data/train.json`) and `tools/make_silencio.py`
(`data/silencio.json`), sharing `tools/layout.py`, which refuses overlapping objects or anyone placed inside
things and writes the guard posts. A map with a `"ground"` key gets its own ground
baked by `gen_assets.py ground` (`"snow"` bakes it white, with `"ice"` for frozen water).
Objects in `world.SNOWY` are baked a second time under snow, their `"snow"` skin, which
a map with `"skin": "snow"` (Silencio) wears in place of the plain look; they're lit
under cloud (`render(overcast=True)`, faint shadows) to go with its `"weather": "snow"`. Character animations are baked in parallel from key poses in
`tools/chars.py` and packed into one atlas per character (about a minute on a multi-core machine). The town layout lives in `data/town.json`.

```bash
python3 -m venv tools/.venv && tools/.venv/bin/pip install -r tools/requirements.txt
tools/.venv/bin/python tools/gen_assets.py            # everything
tools/.venv/bin/python tools/gen_assets.py chars ui   # or just some: chars world fx ui sfx animals ground
SUNDANCE_TEMPLATES=veteran tools/.venv/bin/python tools/gen_assets.py chars   # re-bake some bodies
SUNDANCE_OBJECTS=coop,hencrate tools/.venv/bin/python tools/gen_assets.py world   # re-bake some world objects
SUNDANCE_GROUNDS=train tools/.venv/bin/python tools/gen_assets.py ground   # re-bake some maps' grounds (town, cruz_verde, train...)
godot --headless --path . --import
```

Flags go after `--`: `--skip-title` (no title or loadout screen; rides in with Colt, coach gun and Winchester, or `--guns=navy,spencer`, one a slot), `--level=ID` (a level from `data/levels.json`, e.g. `san_miguel_35`), `--at=GX,GY` (start tile), `--bot` (autopilot that shoots
and logs hits and bandit reactions; `--bot=miss` shoots just past them), `--alert` (trigger the close-up), `--rattle` (near-miss every bandit once), `--freeze` (no title, bandits stand still), `--shot=PATH --shot-time=SECONDS` (save a
screenshot and quit). The window opens maximized; a screenshot at a set size needs a small
script that calls `DisplayServer.window_set_mode(WINDOW_MODE_WINDOWED)` and
`window_set_size` before loading the scene (headless runs always play at 1280x720).

## Releases

Publishing a release on GitHub (Releases > Draft a new release, a tag like `v0.1.0`,
Publish) runs `.github/workflows/release.yml`. It exports the three presets in
`export_presets.cfg` with Godot 4.7.2 on a GitHub Linux runner and attaches them to the
release some minutes later:

- `sundance-0.1.0-windows.zip`: one `Sundance.exe`, the game packed inside
- `sundance-0.1.0-macos.zip`: `Sundance.app`, universal (Intel and Apple Silicon)
- `sundance-0.1.0-linux-x86_64.tar.gz`: one `Sundance.x86_64`
- `SHA256SUMS`

The tag, less its `v`, is written into `application/config/version` for the build and shown
in the corner of the title card; a build from the editor has no version and shows none.
Actions > Release > Run workflow makes the same builds as a workflow artifact, without a
release, to try the pipeline out. No tests run in it.

The builds aren't signed (the Mac app only ad hoc), so worth a line in the release notes:
on Windows, SmartScreen's "More info > Run anyway"; on macOS, after unzipping,
`xattr -cr Sundance.app` (or System Settings > Privacy & Security > Open Anyway).

To export locally, install the 4.7.2 export templates (Editor > Manage Export Templates),
then `godot --headless --path . --export-release macOS build/macos/Sundance.zip`
(or `Windows`, `Linux`); `build/` is ignored.
